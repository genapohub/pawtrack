## 主要阻断

1. 标准后端启动被 Prometheus `should_gzip` 参数不兼容阻断；Motor 与未锁定 PyMongo 另有兼容性错误。
2. Docker 初始化 SQL 与 ORM 模型不一致，按脚本建库后注册接口因缺少 `users.invite_code` 返回 500。
3. 支付回调无平台签名验证，可直接将会员订单改为已支付并开通订阅。
4. 碰头接口存在旁观者读取距离、完成领奖、取消他人碰头，以及未满足 `<5m` 也可完成的安全缺陷。
5. 设备可被其他用户重新绑定抢占；定位上报无设备认证。
6. 微信登录因手机号非空约束返回 500；报警设置读取路由冲突、更新存在未定义名称。
7. 后台用户、设备、报警、订单列表因 `WHERE true()` SQL 语法错误返回 500。
8. 历史轨迹始终返回空数组。

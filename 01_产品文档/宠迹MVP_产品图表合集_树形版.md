## 图 2 · 业务逻辑图（3 输入 → 6 核心逻辑 → 4 变现输出）

```
🐾 宠迹 MVP 业务逻辑链路
│
├── 📥 数据输入层（3 源）
│   ├── 定位数据：GPS + WiFi + 蓝牙三源融合定位
│   ├── 围栏配置：猫默认 100m / 狗默认 300m，可自定义
│   └── 宠物类型：猫/狗选择决定后续全部分支逻辑
│
├── ⚙️ 核心逻辑层（6 链）
│   ├── 猫狗分支判断
│   │   ├── 猫咪路径：宅家监控 → 离家报警（默认开启）→ 安全围栏严控
│   │   ├── 狗狗路径：户外活动 → 状态展示 → 社交匹配 → 碰头奖励
│   │   └── 共同路径：设备异常检测 → 低电量/离线/拆卸报警
│   ├── 设备状态检测
│   │   ├── 在线 → 正常定位服务
│   │   ├── 离线 → 最后位置记录 + 离线报警推送
│   │   ├── 低电量 → 20% 预警 / 10% 紧急提醒
│   │   └── 拆卸 → 立即报警 + 紧急联系人通知
│   ├── 附近宠物可见性
│   │   ├── 隐私开关：仅好友可见 / 全部可见 / 不可见
│   │   ├── 距离过滤：500m / 1km / 3km 三档
│   │   └── 匿名模式：只显示类型不显示名称
│   ├── 积分收支逻辑
│   │   ├── 获取：碰头 +100 / 邀请 +50 / 签到 +5 / 活动奖励
│   │   ├── 消费：商城兑换 / 服务抵扣 / 会员折扣
│   │   ├── 过期：12 个月未使用自动清零
│   │   └── 明细：收支记录实时可查
│   ├── 核心业务规则
│   │   ├── 猫狗分区策略：猫默认离家报警开启且不可关闭（仅可调围栏范围）；狗默认关闭可手动开启
│   │   ├── 碰头防作弊：>50m 才可发起 + 同一对手每日限 1 次 + 后台异常审核 + 虚假碰头扣积分
│   │   ├── 订阅触发点：5 分钟刷新→5 秒实时 / 7 天→无限轨迹 / 1 台→多台设备 / 基础→高级报警
│   │   ├── 设备异常优先级：拆卸 > 离线 > 低电量，高级别报警覆盖低级别避免通知轰炸
│   │   └── 积分风控：单日获取上限 500 + 异常获取自动冻结 + 后台人工审核
│   └── （输出流转）→ 变现输出层
│
└── 💰 变现输出层（4 通道）
    ├── 订阅转化：免费功能限制 → 会员解锁触发点
    ├── 硬件复购：多宠家庭优惠 + 配件推荐
    ├── 社交变现（V2）：品牌合作 + 活动引流
    └── 增值服务：保险 / 商城 / 服务推荐
```

## 图 3 · 业务流程图（7 阶段用户旅程 + 5 判断节点）

```
🐾 宠迹 MVP 用户旅程（7 阶段增长飞轮）
│
├── Phase 1 · 注册激活
│   └── 手机号/微信/Apple ID 注册 → 创建账号 → 添加宠物（选猫/狗）→ 绑定定位器 → 配对成功 → 进入首页
│       ⚠️ 关键：猫/狗选择影响后续所有默认配置
│
├── Phase 2 · 日常使用
│   └── 打开 App → 查看地图定位 → 查看宠物状态（在家/户外/宅家）→ 附近宠物 → 历史轨迹
│       ⚠️ 核心场景：主人随时确认宠物位置和状态
│
├── Phase 3 · 安全报警
│   └── 宠物离开围栏 → 判断猫/狗类型 → 猫：默认触发离家报警（不可关闭）/ 狗：检查是否开启报警
│       → 推送通知 → 主人确认 → 定位追踪
│
├── Phase 4 · 设备异常
│   └── 设备状态检测 → 低电量（20% 预警 / 10% 紧急）→ 离线 → 拆卸
│       ⚠️ 优先级：拆卸 > 离线 > 低电量
│
├── Phase 5 · 社交互动（V2）
│   └── 社交首页 → 寻找好朋狗 → 匹配列表 → 发起碰头（>50m 校验）→ 实时距离倒计时 → 到达（<5m）碰头成功
│       ⚠️ 狗专属路径
│
├── Phase 6 · 商业变现
│   └── 免费功能限制触发 → Pro 会员订阅 → 硬件销售/复购 → 增值服务（保险/商城）→ 社交变现（品牌/活动）
│       ⚠️ 三层变现：硬件 + 订阅 + 增值
│
└── Phase 7 · 留存循环
    └── 碰头奖励 + 积分体系 + 邀请好友 → 社交关系沉淀 → 复购/续费 → 增长飞轮

关键判断节点说明（5 个）
├── 猫/狗类型判断 → 影响报警默认策略、状态展示方式、社交可用性、围栏默认范围
├── 围栏进出判断 → GPS 坐标与围栏圆心距离 vs 半径，进出状态切换触发状态变更和报警
├── 碰头距离判断 → >50m 允许发起 / 50m~5m 寻找中 / <5m 碰头成功
├── 会员功能判断 → 刷新频率 / 轨迹天数 / 设备数量 / 报警通道，4 维度限制触发订阅
└── 设备状态判断 → 在线 / 离线 / 低电量 / 拆卸，不同状态不同报警策略
```

```
│   ├── 报警统计：报警次数 / 类型分布 / 处理率
│   └── 营收趋势：MRR / ARR / ARPU

├── 👥 用户管理
│   ├── 用户列表：多维筛选 + 批量操作
│   ├── 用户详情：宠物 / 设备 / 订单 / 报警联动
│   ├── 封禁管理：即时生效 + 解封审批
│   └── 实名认证：审核通过 / 拒绝
│
├── 🐾 宠物管理
│   ├── 宠物列表：按品种 / 类型 / 状态筛选
│   ├── 宠物详情：档案 + 位置 + 报警历史
│   ├── 品种库维护：品种信息 + 默认配置
│   └── 类型审核：异常类型标记

├── 📡 设备管理
│   ├── 设备列表：在线 / 离线 / 低电量状态

│   ├── 固件升级：版本管理 + 批量推送
│   └── 异常监控：离线 / 拆卸 / 故障告警
│
├── 🔔 报警管理
│   ├── 规则配置：猫 / 狗独立默认规则
│   ├── 报警记录：按类型 / 时间 / 状态筛选
│   ├── 通知通道：Push / 短信 / 紧急联系人
│   └── 误报标记：优化报警准确率
│
├── 🐕 社交管理（V2）
│   ├── 碰头审核：异常碰头标记 + 审核
│   ├── 积分规则：获取 / 消费 / 过期配置
│   ├── 好朋狗配置：匹配算法参数调整
│   └── 作弊检测：频率 / 距离 / 模式识别
│
├── 💰 会员营收
│   ├── 方案管理：三档方案 + 功能对比
│   ├── 订单列表：按状态 / 类型筛选 + 退款
│   ├── 收入统计：MRR / ARR / 渠道分布
│   └── 积分管理：余额 / 流水 / 过期
│
├── 📢 内容管理
│   ├── 公告管理：定时发布 + 推送范围
│   ├── 帮助中心：FAQ + 使用指南
│   ├── Banner 管理：首页轮播 + 活动页
│   └── 活动管理：限时活动 + 积分活动
│
└── ⚙️ 系统设置
    ├── 角色权限：超级管理员 / 运营 / 客服
    ├── 操作日志：全量审计 + 敏感操作高亮
    ├── 系统配置：全局参数 + 功能开关
    └── 数据导出：异步生成 + 下载

角色权限矩阵（3 角色）
├── 超级管理员 → 全部 9 模块读写 + 角色管理 + 系统配置 + 数据导出
├── 运营人员 → 用户管理（读+封禁）+ 宠物/社交/内容管理（读写）+ 报警管理（读）
└── 客服人员 → 用户/宠物/设备（读）+ 报警（读写）+ 订单（读+退款）

前后端数据联动机制
├── 实时同步（≤1 秒）：用户封禁→前端即时拦截登录；报警规则变更→前端下次报警生效；会员权益变更→前端实时刷新
├── 准实时同步（≤5 分钟）：公告推送→前端下次启动展示；Banner 配置→前端下次刷新加载；固件升级→设备下次在线推送
├── 异步同步（T+1）：收入统计→次日数据完整；积分过期→每日凌晨批量执行；数据导出→异步生成下载链接
└── 审核机制：碰头积分异常→后台标记→前端扣分+通知；退款申请→后台审批→前端订单变更+到账通知
```

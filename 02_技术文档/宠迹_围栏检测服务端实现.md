## 1. 检测方案总览

### 1.1 为什么服务端检测而非设备端

| 方案 | 优势 | 劣势 |
|------|------|------|
| **服务端检测（已落地）** | 统一逻辑、可更新围栏配置、支持历史轨迹分析、误报过滤 | 需要服务端计算资源 |
| 设备端检测 | 实时性高、省电 | 设备算力有限、配置更新困难、无法处理复杂围栏 |

**结论**：服务端检测，设备端辅助（低电量时设备自行报警）。

### 1.2 检测触发时机（MVP 已落地）

| 触发方式 | 频率 | 说明 |
|---------|------|------|
| 定位上报触发 | 每次上报 | `POST /api/v1/devices/location/upload` 时同步检测（见 3.1） |
| 手动检测接口 | 按需 | `POST /api/v1/alarms/fence-check`（body: device_id/lat/lng）（管理/测试用） |
| 定时扫描 | V2 规划 | 防漏检兜底（MVP 阶段上报即检已覆盖主链路） |

## 2. 核心算法：Haversine 距离公式

### 2.1 为什么改用 Haversine（2026-08-09 决策）

| 维度 | PostGIS（原方案） | **Haversine（现方案）** |
|------|------------------|------------------------|
| 依赖 | 需 Docker 安装 PostGIS 扩展 | **零依赖，标准库 math** |
| 存储 | GEOGRAPHY 类型 | DECIMAL(10,7) 经纬度双字段 |
| 精度 | 亚米级 | 米级（宠物围栏场景足够） |
| 查询性能 | 空间索引 | 逐条计算（MVP 设备量级无压力） |
| 迁移成本 | — | V2 可平滑升级 PostGIS |

### 2.2 Haversine 公式（代码实现，`alarms.py`）

```python
import math
from decimal import Decimal

EARTH_RADIUS_M = 6371000.0  # 地球平均半径（米）

def haversine_distance(
    lat1: Decimal, lng1: Decimal,
    lat2: float, lng2: float
) -> float:
    """计算两点间球面距离（米）"""
    phi1, phi2 = math.radians(float(lat1)), math.radians(lat2)
    d_phi = math.radians(lat2 - float(lat1))
    d_lambda = math.radians(lng2 - float(lng1))

    a = math.sin(d_phi / 2) ** 2 + \
        math.cos(phi1) * math.cos(phi2) * math.sin(d_lambda / 2) ** 2
    return 2 * EARTH_RADIUS_M * math.asin(math.sqrt(a))
```

```python

@router.post("/fence-check")
async def check_fence(device_id: int, db: AsyncSession = Depends(get_db)):
    # 1. 查设备 → 绑定宠物
    device = await db.get(Device, device_id)
    pet = (await db.execute(
        select(Pet).where(Pet.id == device.pet_id, Pet.fence_enabled.is_(True))
    )).scalar_one_or_none()

    if not pet or not pet.fence_center_lat or not pet.fence_center_lng:
        return {"checked": False, "reason": "围栏未配置"}

    # 2. 获取设备最新位置（Redis GEO）
    geo = await redis_client.geopos("location:geo:nearby", str(device.id))
    if not geo or not geo[0]:
        return {"checked": False, "reason": "无最新位置"}

    lng1, lat1 = geo[0]  # Redis 返回 (lng, lat)
    lat2, lng2 = float(pet.fence_center_lat), float(pet.fence_center_lng)

    distance = haversine_distance(Decimal(lat2), Decimal(lng2), lat1, lng1)

        return {"checked": True, "inside": False, "distance": distance}
    return {"checked": True, "inside": True, "distance": distance}
```

## 4. 误报过滤策略

### 4.1 常见误报原因与处理

| 原因 | 过滤策略 | MVP 状态 |
|------|---------|:---:|
| GPS 漂移（室内） | 室内定位不触发围栏报警 | ⚠️ 数据字段预留 |
| 短暂离开（<30秒） | 延迟确认机制 | ⚠️ V2 规划 |
| WiFi 定位误差 | 精度 >50m 不触发 | ⚠️ 数据字段预留 |
| 重复上报 | **5 分钟防重复已落地**（同宠物同类型 active 去重） | ✅ |

### 4.2 防重复报警（已落地）

```python
recent = await db.execute(
    select(Alarm).where(
        Alarm.pet_id == pet.id,
        Alarm.type.in_([AlarmType.leave_fence, AlarmType.leave_fence_cat]),
        Alarm.status == AlarmStatus.active,
        Alarm.created_at > datetime.utcnow() - timedelta(minutes=5),
    )
)
if recent.scalar_one_or_none():
    return {"checked": True, "inside": False, "skipped": "recent_alarm"}
```

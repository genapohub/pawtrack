## 1. 检测方案总览

### 1.1 为什么服务端检测而非设备端

| 方案 | 优势 | 劣势 |
|------|------|------|
| **服务端检测（推荐）** | 统一逻辑、可更新围栏配置、支持历史轨迹分析、误报过滤 | 需要服务端计算资源 |
| 设备端检测 | 实时性高、省电 | 设备算力有限、配置更新困难、无法处理复杂围栏 |

**结论**：服务端检测，设备端辅助（低电量时设备自行报警）。

### 1.2 检测触发时机

| 触发方式 | 频率 | 说明 |
|---------|------|------|
| 定位数据上报 | 实时（每 10 秒） | 通过 Redis Stream 消费者触发 |
| 定时扫描 | 每 5 秒 | 兜底，防止消费者漏检 |
| 配置变更 | 即时 | 围栏配置更新后立刻触发一次检测 |

## 2. PostGIS 核心函数

### 2.1 `ST_DWithin` — 距离检测

```sql
-- 判断设备是否在围栏内（距离围栏中心 <= 半径）
SELECT ST_DWithin(
    fence_center::geography,      -- 围栏中心（GEOGRAPHY类型）
    location::geography,          -- 设备当前位置
    fence_radius                  -- 围栏半径（米）
) AS is_inside;
```

**返回值**：`true`（在围栏内）/ `false`（离开围栏）

### 2.2 `ST_Distance` — 距离计算

```sql
-- 计算设备到围栏中心的实际距离（米）
SELECT ST_Distance(
    fence_center::geography,
    location::geography
) AS distance_meters;
```

### 2.3 `ST_SetSRID` + `ST_MakePoint` — 构建坐标点

```sql
-- 将经纬度构建为 GEOGRAPHY 点
SELECT ST_SetSRID(ST_MakePoint(lng, lat), 4326)::geography;
```

## 3. 完整 SQL 实现

### 3.1 实时围栏检测 SQL

```sql
-- 检测所有开启围栏的设备是否离开围栏
-- 输入：设备最新位置（从 Redis Stream 消费者传入）
-- 输出：触发报警的设备列表

INSERT INTO alarms (pet_id, user_id, device_id, type, severity, lat, lng, address, status, created_at)
SELECT 
    p.id AS pet_id,
    p.user_id,
    d.id AS device_id,
    CASE 
        WHEN p.type = 'cat' THEN 'leave_fence_cat'
        ELSE 'leave_fence'
    END AS type,
    CASE 
        WHEN p.type = 'cat' THEN 'high'    -- 猫咪离家 = 高优先级
        ELSE 'medium'
    END AS severity,
    ST_Y(la.location::geometry) AS lat,
    ST_X(la.location::geometry) AS lng,
    reverse_geocode(ST_Y(la.location::geometry), ST_X(la.location::geometry)) AS address,
    'active' AS status,
    NOW() AS created_at
FROM pets p
JOIN devices d ON d.pet_id = p.id AND d.status = 'online'
JOIN (
    -- 获取每个设备的最新位置（从 locations_archive 或 Redis Geo）
    SELECT DISTINCT ON (device_id) 
        device_id, location, created_at
    FROM locations_archive
    WHERE created_at > NOW() - INTERVAL '10 seconds'
    ORDER BY device_id, created_at DESC
) la ON la.device_id = d.id
WHERE p.fence_enabled = true
  AND NOT ST_DWithin(
      p.fence_center::geography,
      la.location::geography,
      p.fence_radius
  )
  -- 防重复报警：同一设备同一围栏配置，5分钟内不重复报警
  AND NOT EXISTS (
      SELECT 1 FROM alarms a2
      WHERE a2.pet_id = p.id
        AND a2.type IN ('leave_fence', 'leave_fence_cat')
        AND a2.status = 'active'
        AND a2.created_at > NOW() - INTERVAL '5 minutes'
  );
```

### 3.2 定时扫描 SQL（兜底）

```sql
-- 每 5 秒执行一次，扫描所有在线设备
-- 使用 pg_cron 或应用层定时任务

SELECT 
    p.id AS pet_id,
    p.user_id,
    d.id AS device_id,
    ST_Distance(p.fence_center::geography, la.location::geography) AS distance_m,
    p.fence_radius
FROM pets p
JOIN devices d ON d.pet_id = p.id AND d.status = 'online'
JOIN locations_archive la ON la.device_id = d.id
WHERE p.fence_enabled = true
  AND la.created_at = (
      SELECT MAX(created_at) FROM locations_archive WHERE device_id = d.id
  )
  AND NOT ST_DWithin(p.fence_center::geography, la.location::geography, p.fence_radius);
```

### 3.3 围栏进入检测（返回围栏）

```sql
-- 检测设备是否进入围栏（从离开状态恢复）
INSERT INTO alarms (pet_id, user_id, device_id, type, severity, lat, lng, status, created_at)
SELECT 
    p.id, p.user_id, d.id,
    'enter_fence' AS type,
    'low' AS severity,
    ST_Y(la.location::geometry), ST_X(la.location::geometry),
    'handled' AS status,   -- 进入围栏自动处理
    NOW()
FROM pets p
JOIN devices d ON d.pet_id = p.id
JOIN locations_archive la ON la.device_id = d.id
WHERE p.fence_enabled = true
  AND ST_DWithin(p.fence_center::geography, la.location::geography, p.fence_radius)
  -- 上次报警是"离开围栏"，现在回来了
  AND EXISTS (
      SELECT 1 FROM alarms a2
      WHERE a2.pet_id = p.id
        AND a2.type IN ('leave_fence', 'leave_fence_cat')
        AND a2.status = 'active'
  );
```

## 4. Python 实现（FastAPI + AsyncPG）

### 4.1 围栏检测服务

```python
import asyncio
import asyncpg
import redis.asyncio as redis
from datetime import datetime
from typing import List, Dict

class FenceDetector:
    def __init__(self, pg_pool: asyncpg.Pool, redis_client: redis.Redis):
        self.pg = pg_pool
        self.redis = redis_client
        self.running = False
    
    async def start(self):
        """启动定时围栏检测（每 5 秒执行一次）"""
        self.running = True
        while self.running:
            try:
                await self.detect_all()
            except Exception as e:
                logger.error(f"围栏检测异常: {e}")
            await asyncio.sleep(5)
    
    async def detect_all(self):
        """批量检测所有在线设备的围栏状态"""
        async with self.pg.acquire() as conn:
            # 1. 查询所有需要检测的设备（开启围栏 + 在线）
            rows = await conn.fetch("""
                SELECT 
                    p.id AS pet_id,
                    p.user_id,
                    p.type,
                    p.fence_center,
                    p.fence_radius,
                    d.id AS device_id,
                    la.location,
                    la.created_at
                FROM pets p
                JOIN devices d ON d.pet_id = p.id AND d.status = 'online'
                JOIN LATERAL (
                    SELECT location, created_at
                    FROM locations_archive
                    WHERE device_id = d.id
                    ORDER BY created_at DESC
                    LIMIT 1
                ) la ON true
                WHERE p.fence_enabled = true
                  AND la.created_at > NOW() - INTERVAL '10 seconds'
            """)
            
            # 2. 批量检测（PostGIS 原生函数，性能高）
            for row in rows:
                is_inside = await conn.fetchval("""
                    SELECT ST_DWithin($1::geography, $2::geography, $3)
                """, row['fence_center'], row['location'], row['fence_radius'])
                
                if not is_inside:
                    await self.trigger_alarm(conn, row)
    
    async def trigger_alarm(self, conn, row: Dict):
        """触发围栏离开报警"""
        # 1. 查重：5分钟内同一设备不重复报警
        recent = await conn.fetchval("""
            SELECT COUNT(*) FROM alarms
            WHERE pet_id = $1
              AND type IN ('leave_fence', 'leave_fence_cat')
              AND status = 'active'
              AND created_at > NOW() - INTERVAL '5 minutes'
        """, row['pet_id'])
        
        if recent > 0:
            return  # 已报警，跳过
        
        # 2. 写报警记录
        lat = row['location'].y  # PostGIS geometry 的 y = lat
        lng = row['location'].x  # x = lng
        
        alarm_id = await conn.fetchval("""
            INSERT INTO alarms (pet_id, user_id, device_id, type, severity, lat, lng, status)
            VALUES ($1, $2, $3, $4, $5, $6, $7, 'active')
            RETURNING id
        """, row['pet_id'], row['user_id'], row['device_id'],
            'leave_fence_cat' if row['type'] == 'cat' else 'leave_fence',
            'high' if row['type'] == 'cat' else 'medium',
            lat, lng)
        
        # 3. 推送报警通知（WebSocket + Push）
        await self.push_alarm(row['user_id'], alarm_id, row['pet_id'], lat, lng)
    
    async def push_alarm(self, user_id: int, alarm_id: int, pet_id: int, lat: float, lng: float):
        """推送报警到用户 App"""
        message = {
            "type": "alarm_triggered",
            "pet_id": pet_id,
            "alarm_id": alarm_id,
            "lat": lat,
            "lng": lng,
            "ts": int(datetime.now().timestamp())
        }
        # 通过 WebSocket 推送到用户的所有在线设备
        await self.redis.publish(f"user:{user_id}:alarm", json.dumps(message))
```

## 5. 误报过滤策略

### 5.1 常见误报原因

| 原因 | 过滤策略 |
|------|---------|
| GPS 漂移（室内） | 室内定位（`is_indoor=true`）不触发围栏报警 |
| 短暂离开（< 30秒） | 延迟 30 秒确认，持续离开才报警 |
| WiFi 定位误差 | WiFi 定位（`source=wifi`）精度 > 50m 时不触发 |
| 多次上报同一位置 | 去重：同一设备 5 分钟内相同位置不重复报警 |

### 5.2 延迟确认实现

```python
async def delayed_fence_alarm(device_id: int, pet_id: int):
    """延迟 30 秒确认围栏离开"""
    # 30 秒后再次检测
    await asyncio.sleep(30)
    
    async with pg_pool.acquire() as conn:
        # 再次查询最新位置
        latest = await conn.fetchrow("""
            SELECT location FROM locations_archive
            WHERE device_id = $1
            ORDER BY created_at DESC LIMIT 1
        """, device_id)
        
        pet = await conn.fetchrow("""
            SELECT fence_center, fence_radius FROM pets WHERE id = $1
        """, pet_id)
        
        if latest:
            is_inside = await conn.fetchval("""
                SELECT ST_DWithin($1::geography, $2::geography, $3)
            """, pet['fence_center'], latest['location'], pet['fence_radius'])
            
            if not is_inside:
                await trigger_alarm(...)  # 确认离开，触发报警
```

```sql
SELECT d.id, la.location
FROM devices d
LEFT JOIN LATERAL (
    SELECT location FROM locations_archive
    WHERE device_id = d.id
    ORDER BY created_at DESC LIMIT 1
) la ON true
WHERE d.status = 'online';

-- 比子查询快 10 倍以上
```

### 6.3 缓存策略

```python
# 围栏配置缓存（Redis，TTL 5 分钟）
# Key: fence:config:{pet_id}
# Value: { "center_lat": 31.23, "center_lng": 121.47, "radius": 100 }

async def get_fence_config(pet_id: int):
    cache_key = f"fence:config:{pet_id}"
    cached = await redis.get(cache_key)
    if cached:
        return json.loads(cached)
    
    config = await pg.fetchrow("SELECT fence_center, fence_radius FROM pets WHERE id = $1", pet_id)
    await redis.setex(cache_key, 300, json.dumps(config))
    return config
```

# 宠迹 PawTrack — 功能结构图（树形）

> 纯 Markdown 树形结构，任何 Markdown 查看器均可渲染

## 📱 前端 App 功能结构（26 屏）

```
📱 前端 App（26 屏 · 6 大流程）
│
├── Flow 1 · 注册激活（4屏 · P0）
│   ├── S1 注册登录
│   │   ├── 手机号 / 微信 / Apple ID 登录
│   │   └── 新用户引导添加宠物
│   ├── S2 地图首页
│   │   ├── 实时定位展示 + 宠物状态 Pin（蓝=狗 / 橙=猫 / 灰=附近）
│   │   └── 右下角 FAB 添加宠物
│   ├── S3 添加宠物
│   │   ├── 选择猫/狗 + 品种 + 名称
│   │   └── 猫狗选择影响后续默认设置（猫默认开报警）
│   └── S4 绑定定位器
│       ├── 扫码配对 / 输入 SN 号绑定
│       └── 绑定成功展示设备状态 + 引导下一步
│
├── Flow 2 · 定位与状态（4屏 · P0/P1）
│   ├── S5 宠物列表 Tab
│   │   └── 宠物卡片列表 + 状态标签（狗：在家/户外；猫：宅家）
│   ├── S6 宠物详情
│   │   ├── 宠物信息 + 设备状态 + 电量
│   │   ├── 报警快捷入口
│   │   └── Pro 功能对比入口
│   ├── S7 历史轨迹
│   │   ├── 时间轴选择 + 轨迹回放
│   │   └── 免费 7 天 / 会员无限（触发订阅转化）
│   └── S8 附近宠物
│       ├── 地图展示附近宠物（受隐私设置控制）
│       └── V2.0 新增：列表/地图 Tab 切换 · map 标记点 + callout 气泡 + 猫狗图例
│
├── Flow 3 · 安全报警（4屏 · P0）
│   ├── S9 报警设置
│   │   └── 围栏报警开关 + 范围设置（猫默认 100m 开 / 狗 300m 关）
│   ├── S10 围栏自定义
│   │   ├── 地图拖拽圆心调整位置
│   │   └── 滑块调整半径 + 实时预览
│   ├── S11 报警通知
│   │   ├── Push + App 内通知 + 紧急联系人
│   │   └── 猫咪离开立即报警 / 狗狗仅开启后报警
│   └── S12 设备状态提醒
│       ├── 低电量 <20% 预警
│       ├── 离线 >30min 报警
│       └── 拆卸检测立即报警
│
├── Flow 4 · 社交碰头（5屏 · P2 ✅ V2.0 已实现）
│   ├── S13 社交首页
│   │   ├── 寻找好朋狗入口 + 碰头入口
│   │   └── 附近活跃狗狗数量 + 待碰头请求
│   ├── S14 好朋狗列表
│   │   ├── 匹配结果 + 距离 + 匹配度百分比（距离40+活跃30+品种基础15）
│   │   └── 按品种 / 距离 / 活跃度筛选；按匹配度降序
│   ├── S15 碰头开始
│   │   ├── 发起请求 + 距离校验（>50m 才可发起，MEET_MIN_DISTANCE=50）
│   │   └── 同一对手每日限 1 次（DAILY_MEET_LIMIT=1）
│   ├── S16 碰头寻找中
│   │   ├── 实时距离环 + 30 分钟倒计时（<5m 变绿触发确认）
│   │   ├── 超时自动取消（后台每 60s 扫描 confirmed > 30min → failed）
│   │   └── 每 5 秒轮询 GET /social/meets/{id}/distance
│   └── S17 碰头成功
│       ├── 双方确认各得 100 积分（MEET_POINTS=100）
│       ├── 积分奖励卡 + 碰头记录卡
│       └── 积分商城跳转 · 返回社交首页
│
├── Flow 5 · 商业变现（4屏 · P0/P1）
│   ├── S18 Pro 入口
│   │   ├── 多触点入口（地图/宠物详情/轨迹/我的）
│   │   └── 功能限制触发升级 + 免费 vs 会员对比
│   ├── S19 会员订阅
│   │   ├── 三档定价：基础 ¥19.9/月 · Pro ¥29.9/月
│   │   └── 年付优惠约 17%
│   ├── S20 积分商城
│   │   └── 兑换宠物用品/优惠券（碰头+邀请+签到+活动获取）
│   └── S21 积分明细
│       └── 积分收支记录（获取/消费/过期）
│
└── Flow 6 · 个人中心（5屏 · P0/P1）
    ├── S22 个人中心
    │   └── 用户信息 + 会员卡 + 功能入口（通知/邀请/设备/设置）
    ├── S23 通知设置
    │   └── 系统消息开关（独立于报警设置）
    ├── S24 邀请好友
    │   ├── 邀请码 + 分享 + 记录
    │   └── 每成功邀请 1 人各得 50 积分
    ├── S25 设备管理
    │   ├── 设备列表 + 绑定/解绑
    │   └── 固件升级（显示状态/电量/版本）
    └── S26 设置
        ├── 账号 / 隐私 / 通用 / 关于
        └── 隐私设置控制位置可见性 + 退出登录
```

## 🖥️ 后台管理系统功能结构（15 屏）

```
🖥️ 后台管理系统（9 大模块 · 15 屏）
│
├── A1 后台登录
│   └── RBAC 4 角色鉴权（超管/运营/客服/财务）
│
├── 📊 数据概览
│   └── A2 Dashboard
│       ├── 核心指标卡：DAU/MAU/设备在线率/报警率/收入趋势（7/30/90天）
│       ├── 报警热力图（地图展示高发区域）
│       └── 实时监控（10 秒自动刷新）
│
├── 👥 用户管理
│   ├── A3 用户列表
│   │   ├── 多维筛选 + 批量操作 + 封禁/解封
│   │   └── 封禁即时生效（前端拦截登录）
│   └── A4 用户详情
│       └── 宠物/设备/订单/报警 4 个 Tab 联动
│
├── 📡 设备管理
│   ├── A5 设备列表
│   │   ├── 在线/离线/低电量状态筛选
│   │   └── 固件批量推送
│   └── A6 设备详情
│       ├── 绑定历史 + 定位轨迹 + 报警记录 + 固件日志
│       └── 设备异常标红高亮
│
├── 🔔 报警管理
│   ├── A7 报警规则配置
│   │   ├── 猫/狗独立默认规则（100m/300m）
│   │   └── 支持自定义覆盖（变更后前端下次生效）
│   └── A8 报警记录
│       ├── 按类型/时间/状态筛选
│       └── 误报标记（用于优化算法）
│
├── 🐾 社交管理
│   ├── A9 碰头记录审核
│   │   ├── 异常碰头标红（距离<50m/频繁碰头）
│   │   └── 审核不通过扣积分 + 通知用户
│   └── A10 积分规则配置
│       └── 获取/消费规则 + 过期策略（变更实时生效）
│
├── 💰 会员与营收
│   ├── A11 会员方案管理
│   │   ├── 三档方案 + 功能对比
│   │   └── 价格变更需审批
│   ├── A12 订单列表
│   │   └── 按状态/类型筛选（退款需审批+通知）
│   └── A13 收入统计
│       ├── MRR/ARR/ARPU + 收入趋势
│       └── 渠道分布（支持导出 Excel）
│
├── 📢 内容管理
│   └── A14 公告/Banner
│       ├── 公告：定时发布 + 推送范围 + 置顶/下线
│       └── Banner：配置 + 链接 + 排序
│
└── ⚙️ 系统设置
    └── A15 系统设置
        ├── 角色权限：RBAC 模型 4 种角色（权限变更即时生效）
        └── 操作日志：全量审计保留 180 天（不可编辑/删除，支持导出）
```

| Flow1 注册激活 | S1 登录 · S2 地图 · S3 添加宠物 · S4 绑定定位器 | P0 |
| Flow2 定位状态 | S5 宠物列表 · S6 宠物详情 · S7 历史轨迹 · S8 附近宠物 | P0+P1 |
